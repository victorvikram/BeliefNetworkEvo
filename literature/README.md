# Literature

Shared papers for the two-paper package. Reference manuals such as the GSS codebook stay
in `docs/`; this folder is for work we cite and argue with.

## Present

- `DellaPosta-PluralisticCollapse-2020.pdf` — DellaPosta, "Pluralistic Collapse: The 'Oil
  Spill' Model of Mass Political Polarization", *American Sociological Review*. The
  closest prior work: he shows beliefs cluster and that clustering increases, using
  zero-order pairwise correlations. Our contribution is the stronger structural claim, so
  the contrast with his estimator matters and is set out in `MEMORY.md`.
